# 📺 UncoveredTV_AI — Retro TV Web App

Una Single Page Application (SPA) liviana y minimalista que recrea la experiencia clásica de una televisión en vivo con funciones de zapping, lista de canales dinámicos y un canal aleatorio de dibujos animados retro.

## 🚀 Características
- **Experiencia de TV en vivo:** Simula transmisión continua utilizando la API de reproductores de YouTube.
- **Canal de Dibujos Animados (TOONS_RANDOM):** Programación aleatoria sin fin de animaciones clásicas.
- **Navegación tipo Zapping:** Controles clásicos `CH +` / `CH -` y selector dinámico de canales.
- **Diseño Responsive & Dark Mode:** Interfaz cómoda optimizada para todo tipo de pantallas.
- **100% Client-Side:** Funciona completamente en el navegador sin necesidad de servidores o bases de datos complejas.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3 (Flexbox & CSS Grid)
- JavaScript (ES6+)
- YouTube IFrame Player API
